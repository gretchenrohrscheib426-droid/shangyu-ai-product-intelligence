# Metric definitions

- Precision = true positive topic labels / all predicted-positive labels. Report both predicted-positive n and development-set n.
- Citation coverage = important claims with traceable supporting references / audited important claims. Literal overlap is necessary but not sufficient for semantic support.
- Unsupported claims = claims whose bounded wording is not supported by supplied sources; distinguish partially supported.
- Comment utilization: selected-to-model / raw, and cited-in-report / selected are different measures.
- Source quality: S official product source; A selected authoritative reporting; B specialist reporting; C reference/wiki; D unknown/community. Hostname matching is a heuristic, not authorship verification.

Independent human blind accuracy, recall on unseen products and business impact: **Not yet measured**.
